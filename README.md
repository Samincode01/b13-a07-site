# 🌿 KeenKeeper

## 📖 Short Description

KeenKeeper is a modern friendship management web application designed to help users build and maintain meaningful relationships. The platform allows users to track interactions with friends, monitor communication habits, and visualize friendship analytics through a clean, responsive, and user-friendly dashboard experience.

Whether it’s a quick text, a phone call, or a video chat, KeenKeeper helps users stay connected with the people who matter most.

# ✨ Key Features

## 📌 Friendship Interaction Tracking
Users can log different types of interactions such as text messages, calls, and video chats to maintain a consistent communication history with friends.

---

## 📊 Interactive Analytics Dashboard
KeenKeeper provides visual analytics using modern pie charts to help users understand their communication patterns and friendship activity.

---

## 📱 Fully Responsive Modern Design
The application is optimized for desktop, tablet, and mobile devices, offering a smooth and visually appealing experience across all screen sizes.

---

## 🎯 Purpose of the Project

The main goal of KeenKeeper is to encourage stronger personal connections by helping users become more mindful about maintaining friendships and regular communication.
